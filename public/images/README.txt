PRODUCT PHOTOS GO IN THIS FOLDER
--------------------------------
1. Compress each photo (free tool: squoosh.app) to under ~300 KB.
2. Use simple lowercase names with dashes, no spaces:  whey-2kg.jpg
3. Drop the file in this folder.
4. In src/data/products.ts add this line to the product:
       image: "/images/whey-2kg.jpg",
